# Source

A dark new-tab feed of public SaaS prototypes from Vercel, Netlify, Lovable, v0, Bolt, and Websim.

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). Set that URL as Chrome’s homepage, or load `extension/` unpacked to replace the new tab (it forwards to the local app).

Optional: copy `.env.example` to `.env` and add a `URLSCAN_API_KEY` if Vercel/Netlify results start rate-limiting.
